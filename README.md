# 🚌 Safar — Bus Ticket Booking (UX Concept)

An interactive web demo of the **Safar** UX concept — rethinking intercity bus ticket booking in Pakistan.

## The problem
Booking an intercity bus still means calling the terminal, queuing at the counter, or fighting clunky websites. No clear timings/prices in one place, no seat choice, and a paper slip you can't lose.

## The demo
Open `safar-booking-ui.html` in any browser (or view it rendered via GitHub Pages if enabled):
1. **Search** — pick route, date, passengers
2. **Compare** — buses side by side with honest timings, PKR pricing, seats-left urgency
3. **Select seats** — visual seat map, transparent fare math, no hidden fees
4. **E-ticket** — digital booking reference, no paper slip

## Design
Part of the Safar UX concept series. Design shots on Dribbble/Behance (links in profile).

Built with plain HTML/CSS/JS — no frameworks, no build step.
